# 🪺 NEST - Notes Exchange and Study Tools

**NEST** is a web-based platform designed to streamline academic collaboration by enabling students to discover, upload, and download verified study materials like notes, previous year papers (PYQs), and other academic resources.

---

## 🛠️ Built With

- **Backend:** Django (Python)  
- **Frontend:** HTML, CSS, Bootstrap, JavaScript  
- **Database:** PostgreSQL (Production), SQLite (Local/Test)  
- **Cloud Storage:** [Cloudinary](https://cloudinary.com/)  
- **Deployment:** [Render](https://render.com/)

---

## 📌 Features

- 🔍 **Search and Explore Notes**  
  Search for materials using keywords, tags, or filters.

- 📝 **Upload Verified Study Notes**  
  Users can upload notes; all uploads are reviewed and approved by an admin.

- 🧾 **Semester-wise Material Browsing**  
  Access resources categorized by semester, subject, and department.

- 📚 **Download Notes & Materials**  
  Download high-quality, verified PDFs stored on Cloudinary.

- ✅ **Admin Approval System**  
  Uploaded notes are moderated before becoming visible to ensure quality content.

- 🏷️ **Tags & Filters**  
  Materials are tagged with course codes, semesters, and subjects for easy filtering.

- 👤 **User Authentication & Profiles**  
  Secure sign-up/login via Django's auth system; users can manage their uploads.

- 🗃️ **My Uploads Dashboard**  
  Users can view, edit, or delete their uploaded materials.

- 📈 **AI-Generated Quizzes** *(Coming Soon)*  
  Generate practice quizzes from previous year question papers using AI.

- ☁️ **Cloud Storage**  
  Fast and scalable file storage using Cloudinary.

- 🌐 **Fully Responsive UI**  
  Mobile-friendly layout using Bootstrap for accessibility across devices.

- 🚀 **Deployed via Render**  
  Hosted on the Render platform using PostgreSQL for production database.
